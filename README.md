# Yuki Design

吴雨晴的中文个人作品集。纯静态 HTML、CSS、JavaScript，Sites 托管。

- `dist/index.html`：首页，作品分类、关于、经历、联系。
- `dist/work/`：三个案例框架，明确标注案例整理状态。
- `dist/resume.html`：可打印、保存为 PDF 的简历。
- `dist/style.css`：响应式视觉与打印样式。
- `dist/script.js`：作品筛选、邮箱复制、简历打印。
- `build.py`：根据现有履历重新生成页面；不改动 CSS / JS。

## 预览

`python3 -m http.server 4173 --directory dist --bind 127.0.0.1`

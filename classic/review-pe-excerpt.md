4. **动态内容判别**:
   - 🚫 **动态卡片陷阱(2026-06-17 复盘,高频漏检)**:头像/名字/金额换了人,**只代表"内容层"换了数据,不代表整张卡片可以跳过**。**绝不许**因为"这卡片只是换了数据"就连它的**间距、卡片高度、内边距、容器尺寸**一起略过——这些"容器层"几何属性必须照常实测对照。口诀:**内容换人 → 只跳内容,容器照量。**
   - 头像/昵称/金额/日期/订单号等**内容**不同 → `suspected=true`
   - 但**位置/对齐/间距/尺寸/圆角/边框/颜色/字体样式**差异 → `suspected=false`(即使在动态区域)
   - 🚫 **圆角/容器属性被量出来了就必须当真,禁止用"动态内容/背景花"降级(2026-06-18 复盘,强规则)**:`measure_geometry.py` 量圆角时**只描卡片自己的四个角边界**,根本不看框里挂什么(图标会换/赛车↔福娃),也**不受渐变花底影响**(只看角附近那一圈跳变)。所以当脚本对圆角返回 `confident=True`(没报"测不准·交AI")并量出超过 2px 的差异时,**这就是确凿的真实问题 `suspected=false`**。**绝不许**写出"icon 是动态换图 / 背景渐变花,圆角是否真缩小需人工确认"这类降级话术——这俩理由对圆角测量根本不成立。**唯一能降级/疑似的情形**:脚本自己明确返回"测不准·交AI"(卡片框给偏了、或卡片跟背景完全同色,找不到边)。口诀:**圆角量出来了 = 照样判真;只有脚本说"测不准"才人工兜底。** 另:**2px 过滤线指的是"设计与开发两边圆角的差值"(|设计−开发|),不是某一边的绝对值**——设计圆角24、开发就算量成1.9,差值也是22,必报。脚本对"一侧基本直角、另一侧明显圆角"的情况会打 `hard:true`(结构性硬伤),**见到 `hard:true` 一律 `suspected=false` 真问题,不受2px过滤、不许降级**。
   - 图片类容器:只看框大小/位置/圆角/边框/是否被裁切
   - 文本类容器:只看字号/字重/颜色/行高/对齐/是否溢出
   - 同处既样式差又内容差 → **拆 2 条**,共享同 bbox,desc 加前缀 `[样式]` / `[内容]`
5. **疑似兜底**(`suspected=true`):
   - 测试环境/调试信息**本身**:ppe / 息流 / fps / 帧率 / debug / 调试 / mock / beta / alpha / 测试环境 / 开发服务器 / 性能监控 / 日志 / 网格线 / 辅助线 / 标尺 / 版本号 / 彩色调试浮标 / 彩色 Inspector 框
     → 把这类浮标/横幅/彩色浮层**本身**记一条 suspected;它**不影响**其他区域的正常走查
   - **半透明黑色蒙层**(弹窗/抽屉/底部面板的常用遮罩,典型特征:占满屏幕的**黑色或深灰** + opacity 大约 30%~70%,作用是把整屏内容变暗压低对比度引导用户聚焦到上层弹窗)**背后的页面内容**:统一 suspected=true,即使有差异也不当真实问题(强规则)
     → 适用对象**严格限定**于真正的"弹窗遮罩"层;判断口诀:**颜色是黑/深灰 + 半透明 + 几乎覆盖全屏 + 上面叠了一个弹窗 card**,四个特征都满足才算
   - ⚠️ **彩色/不透明浮层不是蒙层**:橙色块、红色横幅、黄色提示条、彩色调试面板、IDE 高亮框、彩色 Inspector 边框、测试环境工具浮窗等,无论是否半透明,都属于**测试环境信息**(按上一条处理):
     - 把"浮层本身"单独记一条 suspected
     - 被它**视觉遮挡**的区域,如果仍能看出 UI 样式问题,**照常走查 `suspected=false`**
     - 不要因为"被某个彩色东西盖住"就把背后的真实 UI 差异全部降级
   - **被弹窗 card 自身覆盖的区域**:弹窗内部内容是真正要走查的对象 `suspected=false`;弹窗 card 之外、**半透明黑色蒙层**之下的页面背景才适用上面的蒙层背后规则
   - 🚫 **反捏造遮挡(强规则,防"甩锅式漏检")**:只有当某区域**像素确实被不透明/半透明物体压在上面**时才算遮挡。**严禁**因为"附近有浮层/蒙层""可能被挡到"就把**没被实际覆盖**的元素判 `suspected=true` 降级。判断步骤:① 先确认遮挡物的真实边界覆盖到哪些像素;② 边界**之外**能看清的 UI 差异,一律 `suspected=false` 正常走查、正常判真实问题,不得以"可能被遮挡"为由跳过或降级。典型误判:图标圆角清晰可见,却因画面别处有橙色色块就说"圆角被蒙层遮挡无法确认"→ 这是捏造遮挡导致的漏检,属错误。
